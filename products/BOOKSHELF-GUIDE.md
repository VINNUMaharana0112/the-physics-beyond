# Bookshelf publishing

The complete content and Bookshelf workflow now lives in the repository's [Publishing guide](../PUBLISHING-GUIDE.md). Use [`content/content-metadata.schema.json`](../content/content-metadata.schema.json) for the shared product metadata contract.

For each listing, provide the product type (physical book, digital download, or affiliate), title, description, author/publisher or brand, format, price and currency when known, availability, product image with alt text, included contents, and fulfillment details. Physical books also need shipping and delivery details; digital downloads need a file and private/public delivery plan; affiliate items need the full tagged retailer URL and a visible disclosure.

The public site currently supports static descriptions and links. There is no checkout database or secure paid-file delivery yet. Do not publish paid files or present an inactive checkout action as purchasable. See the guide for the complete workflow and pre-publish checklist.
